# Skill: Write a Unit Test

## Test location
Mirror the main package structure under `src/test/java/com/croman/singlevendorecommerce/`.

Example: service at `service/products/CategoryService.java` → test at `service/products/CategoryServiceTest.java`

## Test framework stack
- JUnit 5 (`@Test`, `@BeforeEach`, `@ExtendWith`)
- Mockito (`@Mock`, `@InjectMocks`, `ArgumentCaptor`, `verify`, `when`)
- AssertJ (`assertThat`, `assertThatThrownBy`)

## Anatomy of a service test

```java
@ExtendWith(MockitoExtension.class)
class MyServiceTest {

    @Mock
    private MyRepository myRepository;

    @Mock
    private MessageService messageService;

    @InjectMocks
    private MyService myService;

    // ─── Fixtures ────────────────────────────────────────────────────────────

    private static final Long ENTITY_ID = 1L;
    private static final String NAME = "Test Name";

    private MyEntity entity;

    @BeforeEach
    void setUp() {
        entity = MyEntity.builder().entityId(ENTITY_ID).name(NAME).build();
    }

    // ─── methodName ──────────────────────────────────────────────────────────

    @Test
    void testMethodNameReturnsExpectedResult() {
        when(myRepository.findById(ENTITY_ID)).thenReturn(Optional.of(entity));

        MyDTO result = myService.getById(ENTITY_ID);

        assertThat(result.getName()).isEqualTo(NAME);
    }

    @Test
    void testMethodNameThrowsWhenEntityNotFound() {
        when(myRepository.findById(ENTITY_ID)).thenReturn(Optional.empty());
        when(messageService.getMessage(eq("entity_not_found"), any(Locale.class)))
            .thenReturn("Entity not found");

        assertThatThrownBy(() -> myService.getById(ENTITY_ID))
            .isInstanceOf(ApiServiceException.class)
            .hasMessageContaining("Entity not found");
    }
}
```

## Key rules

### Method naming
`test` + camelCase description. No underscores.
- `testGetCategoryByIdReturnsName` ✅
- `getCategoryById_success` ❌

### Fixtures
- Declare test data constants (`static final`) and a `@BeforeEach` that builds the entity using `.builder()`
- Group tests with ASCII section comments: `// ─── methodName ────────`

### Mocking MessageService
Always mock message service for error-path tests — it's called on every `ApiServiceException`:
```java
when(messageService.getMessage(eq("some_key"), any(Locale.class))).thenReturn("Some message");
```

### Asserting ApiServiceException
Use `assertThatThrownBy` + `.isInstanceOf(ApiServiceException.class)`:
```java
assertThatThrownBy(() -> service.doSomething())
    .isInstanceOf(ApiServiceException.class)
    .hasMessageContaining("expected text");
```
To also check metadata (e.g. `categoryId` returned on conflict):
```java
.satisfies(ex -> assertThat(((ApiServiceException) ex).getMetadata())
    .containsEntry("entityId", ENTITY_ID));
```

### Verifying repository not called
```java
verify(myRepository, never()).save(any());
verifyNoInteractions(myRepository);
```

### Capturing arguments
Use `ArgumentCaptor` when you need to assert on what was saved:
```java
ArgumentCaptor<MyEntity> captor = ArgumentCaptor.forClass(MyEntity.class);
verify(myRepository).save(captor.capture());
assertThat(captor.getValue().getName()).isEqualTo("expected");
```
Or use `argThat` inline:
```java
verify(myRepository).save(argThat(e -> "expected".equals(e.getName())));
```

### Soft-delete tests
Always test both "not found" and "soft-deleted" paths separately — `findById` returns soft-deleted records:
```java
@Test
void testGetByIdThrowsWhenSoftDeleted() {
    entity.setDeletedAt(LocalDateTime.now());
    when(myRepository.findById(ENTITY_ID)).thenReturn(Optional.of(entity));
    // ... assert 404
}
```

### Paginated results
```java
Page<MyEntity> page = new PageImpl<>(List.of(entity));
when(myRepository.findAllNotDeleted(any(Pageable.class))).thenReturn(page);
```

## What NOT to test
- Spring auto-wiring / DI configuration
- Framework behavior (Spring Data, Flyway)
- Getters/setters generated by Lombok
- Simple DTO mapping that has no branching logic

## Running tests
```bash
./mvnw test
```

## Before you commit
- [ ] At least one happy path test per public service method
- [ ] At least one not-found / error path test per method that can throw
- [ ] Soft-delete check tested separately from not-found
- [ ] No hardcoded Spanish strings in assertions — use the mocked return value
- [ ] `verify(repository, never()).save(any())` on all paths that should not persist
